# Support

Use the [WordPress.org support forum](https://wordpress.org/support/plugin/post-type-switcher/)
for installation and usage questions. Use GitHub Issues for reproducible defects
and narrowly scoped enhancements, and
[GitHub Discussions](https://github.com/JJJ/post-type-switcher/discussions) for
broader development conversations.

Report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/JJJ/post-type-switcher/security/advisories/new),
not in a public issue or discussion.
